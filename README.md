## 体验

Windows 安装 Node.js 后双击 `start-demo.cmd`，或运行：

```sh
node tools/serve.mjs
```

电脑打开 http://localhost:4178/ 。手机连接同一 Wi-Fi，打开终端打印的局域网地址。当前开发电脑为 http://192.168.8.47:4178/ 。工程包包含已构建的 `dist/`，不用先安装开发依赖。保持服务窗口开启。

也可在已构建目录使用 Python：`python -m http.server 4178 --bind 0.0.0.0 --directory dist`。

## 开发

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

开发构建写入 `dist-v2/`；交付包将最终构建整理到 `dist/`。测试需 Playwright 和 Chrome，默认读取本机 Chrome，可按脚本调整路径。

```powershell
$env:GAME_URL='http://localhost:4178/'
node tests/v2-browser.mjs
node tests/v2-polish.mjs
```

## 当前玩法

- DM 输入31或点“31 · 整线巧解”：6×6、仅取每列底牌、取走即下落、六张同牌整行/列消除。需清空牌且完成2条整线；上方显示下一张待补牌。固定48张普通牌，先横后竖可达成目标。
- 已修复第21/23/25/30关：每张离开棋盘即补位，磁铁/暂存/爆破也会压实空洞。旧V4队列存档可迁移，保留进度与道具。

- 第 17/26 关龙头实验：连续手动配对 2 次触发；第 19/29 关自动转轮：3 次触发。每关各有 3 次机会，自动消除不会继续充能。第 20 关“回流棋局”：普通配对顺转，特殊配对逆转。
- 移位牌从第4关起每关2对，第16关起3对；爆破第7关1对，第8关起2对，第21关起3对。移位重复奖励存为最多3次后续机会，仍只有一个暂存格。
- 宝箱和爆炸使用从原 APK Spine 动画导出的透明帧。奖励揭晓、飞入道具栏后才增加显示数量；转轮智慧积分也在飞行结束后更新。

- 首页和游戏页右下的 DM 可输入 1—31 直接跳关；快捷入口为暂存 2、翻牌 5、爆破 7、礼盒 13、随机礼盒 14。点“2 · 暂存教学”会重播暂存教学。
- 原版手指连续指引：启用暂存、选牌、取回、配对重新上锁。完成全流程才记为已学会，不消耗线索。
- 每局首次点受阻牌播放一次提示音，之后只保留视觉反馈；继续存档也保留该状态。
- 第 16/18/28 关外圈每配对一次旋转一格；第 21/23/25/30 关各列前端取牌、取走立即向上补位。第 24 关每 6 秒向右、第 27 关每 6 秒向上传送；停稳后可点。
- 原版 Good/Great/Excellent/Amazing/Unbelievable 文字、声音、彩色四格、闪光与花瓣反馈。额外不匹配入槽中断当前连击，本局最高边框保留。
- 第 22 关起，两次 Unbelievable（持续连击 25、30 次）触发一次 12 秒限时礼盒机会。两张需配对，超时共同消退，包括已入四格的一张。奖励仍为 85% 正向、15% 轻负向。DM 的“限时宝箱演示”可直接体验，属于测试入口。

- 普通牌必须上方无遮挡、左右至少一侧空开，点击后才可飞入顶部四格。
- 匹配牌相邻插入、自动消除，剩余牌补位；四张不匹配会进入满槽恢复面板。
- 右侧独立暂存格需移位牌解锁；可放表面或槽内普通牌，直到该牌真正配对消除才重新锁定。
- 蓝背牌先翻面，再点击入槽。爆破最多两对，不清整屏。
- 礼盒通常 85% 正向、15% 最多四张轻遮盖；首次礼盒教学固定回退 +1 并明确提示。
- 洗牌、磁铁、线索、回退；IQ 是游戏表现值，排行榜只记录本机成绩。
