# 2.4：让特殊牌反复有用，让惊喜实际到账

本文为2.4历史记录。当前2.7已加入首次六张普通叠牌、槽位不安全时暂缓发牌，后续混合结果以普通牌为主；礼盒概率改为70/30。现行规则以README和总结文档为准。

## 原版资源与反馈

此前宝箱采用静态部件拼接，且 Unity 导入后的图集分辨率与原 atlas 声明不一致，造成盒盖与提手裁切错误。现在用原始 GameGiftUI 的盒身、盒盖、光效骨骼和纹理，经 Spine 4.1 运行时导出透明帧。

- 宝箱原动画：2.167 秒、52 帧；实际原Prefab骨骼组成与图层顺序经过核对。
- 爆竹冲击原动画：0.833 秒、20 帧；按合法牌对先飞入爆竹，命中后收牌。目标不再提前从棋盘消失。
- 转轮使用原 APK SlotMachine 的 Down 皮肤和喷出动画。单窗口自动滚动奖励图标，然后播放原生喷出光效。
- 奖励揭晓使用原光芒、道具底盘、数量角标和星点。显示库存与规则库存分开，图标落到按钮后才跳数；智慧积分同样延迟到飞行结束。
- 新增春节龙头为内置生图生成的透明素材，保留源输出来源；其余普通麻将、道具和上述特效继续复用 APK 资源。

可核对资料：`research/reward-fx/README.md`、`timelines.json`、`gift-crop-comparison.jpg`；烘焙与逐帧验证清单在 `public/assets/reward-fx/baked/`。录像在点击收集前结束，因此库存飞行的精确时序不是从录像逐帧恢复；骨骼内部动画为原资源，多组件同时启动，原脚本间的延迟未恢复。不将这些部分声称为完全相同。

## 特殊牌频率与补偿

| 关卡 | 移位牌对数 | 爆破牌对数 |
|---|---:|---:|
| 1 | 0 | 0 |
| 2—3 | 1 | 0 |
| 4—6 | 2 | 0 |
| 7 | 2 | 1 |
| 8—15 | 2 | 2 |
| 16—20 | 3 | 2 |
| 21—30 | 3 | 3 |

多放特殊牌不能只增加无效消除。暂存已开启或牌仍等待配对时，再消移位牌会储存一次机会，最多3次。当前暂存牌匹配后仍上锁；玩家点击“点击启用”才消耗一份储备，绝不会变成多个暂存格。

爆破不突破普通取牌合法性。若没有合法目标且四格容量允许，则明确转为线索 +1；容量不足不发额外补偿。第7关首次教学已经重排，认证路径确实爆破两对；第21/25关三次爆破均有真实目标。30关认证路径中53/60次爆破有真实目标，其余按补偿规则处理。

## 三组实验

**龙息庭院／卧龙回礼（17、26）**：上下各有一个春节龙头，交替响应。连续手动配对2次，吐出道具、将一整对表面普通牌转化为移位／爆破牌，或龙息自动收取一对合法普通牌。图标和牌从龙口飞向实际目的地。每关最多3次。

**三连惊喜／幸运边台（19、29）**：连续手动配对3次自动滚动，不需额外点击。结果包含道具、整对特殊牌、智慧积分；道具奖励有8%的双份分支。洗牌结果加库存，不强制打散玩家正在规划的棋盘。智慧积分是游戏分，不是智力测量。每关最多3次。

**回流棋局（20，本轮提出的原创关卡实验）**：配对普通牌让外圈顺时针一步，配对特殊牌让外圈逆时针一步。没有新按钮或货币；玩家用消除顺序控制开路方向，把特殊牌从单纯奖励变为可规划的棋盘操作。

吐牌采用整对转换，保留牌数与成对关系，不无限增牌。额外不匹配的手动选牌会打断角色充能；自动爆破、磁铁、限时奖励的连锁不反向充能。随机状态可存档和撤回，不能通过自动效果形成无限奖励循环。

## 验证与迭代结论

- 65 项核心／关卡测试通过，30关均有包含实际特殊效果的完整路径；定时传送各相位、暂存储备、正负礼盒、回退和存档都有验证。
- 独立复核覆盖30关认证路径的2,134个状态，实际提示调用零失败，最长15.86ms。增加了精确规则状态的增量路径缓存，解决新关卡默认搜索预算下提示失效的问题。
- 浏览器触摸点玩17/19/26/29关，分别完成三次自然触发；验证20关逆转与回退。
- 专项验证奖励飞行前不加数、飞行抵达后才加数，所有爆破目标在发射时仍可见；IQ同样延后到账。首次暂存完整手指教学回归通过。
- 整包检查发现并修复 DM 点击穿透：DOM 弹层期间禁用棋盘输入，旧界面按钮校验所属界面代次，避免点“限时宝箱演示”误触已销毁首页的开始按钮。正式模式跳关与暂存教学已经回归。
- 此为后段小规模玩法实验，不宣称随机奖励一定提升长期留存。关键下一轮观察是玩家能否预测下一次效果、是否主动利用顺逆转，以及奖励动画是否打断思考。

手机尺寸浏览器触摸模拟不等于所有机型的真机验收。关卡牌面配置已更新，旧未完成局可能需要重开；完成记录仍保留。
