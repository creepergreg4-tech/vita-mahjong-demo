# 2.5 整线巧解实验与补位修复

## 先修用户反馈的卡关

第21/23/25/30关的上行队列改为“任何牌离开棋盘，立即压实所在队列”。普通取牌无需等待配对；暂存、磁铁和爆破都走相同的补位流程。磁铁取走中段或同列两张牌时，也不会遗留内部空洞。

环形旋转仍然配对触发，周期传送仍然定时触发，不把所有机制混为一种。底层规则、可点击前端、求解器、动画快照和回退同步更新。点击未开放牌时，反馈标记当前前端，而非已经移走的旧牌。

规则版本升至5。旧V4队列存档先验证原布局，再在克隆的当前状态/历史中压实空位，不增加得分、不改变随机种子或道具。验证通过后继续原局；异常存档不会被盲目修补。

## 独立实验31：整线巧解

原30关主线保留。DM输入31、顶部快捷入口或选关面板底部按钮均可进入。

- 棋盘6列×6行，总共48张固定普通牌，四种牌面，各牌总量为偶数。剩余牌从上方补入，每列显示下一张和剩余数量。
- 只有每列底部亮起的牌可收进原四格。取走一张就向下补位，既符合最新补位要求，也允许通过单次选择调整整列。
- 每次补位后检查完整六张同牌的横排或竖列，整线自动消除，再补位、再检查。
- 横排优先，逐条结算后重新检测；交叉不会按11张的并集消除，始终保持各牌面余量成对。
- 清空全部牌且完成至少2条整线才获胜。仅清空但不足目标，会显示明确的失败说明与回退/重试选项。
- 本关不加入角色随机奖励、限时礼盒或特殊牌，先验证“选择取牌，主动制造整线”的基本乐趣。

教学设计有真实的先后顺序：先取一张杂牌，使底部凑成整行；随后取另一张与槽内配对，同时释放左侧整列。认证成功路线36次取牌，确实包含横消、竖消各一次。另一条42次取牌路线也能清空，但只达成1/2，不能把普通二合清场当作通关。

首次引导使用原版手指。首条线成功后停止指路，让玩家自己观察第二条。线索仍需使用原道具。整线演出为逐张点亮、原版光带贯穿、同步碎片、下落补齐；目标数字在实际消除时更新。

磁铁、洗牌、回退均覆盖此模式。洗牌属于救场工具，会验证新的排列能够达成剩余目标；认证教学路线不使用工具。回退可恢复一整次取牌及其后续整线连锁，结果计数和存档一起还原。

## 验证

- TypeScript通过；78项规则/关卡测试通过，包含原30关、周期传送全部相位、新实验胜败路线、交叉整线奇偶性、工具、历史、旧存档迁移。
- 独立复核4,882个随机可达状态：队列连续无洞、仅前端可取、存档恢复有效。
- 浏览器触摸实测21单张取走、磁铁、回退及旧V4存档从首页继续；31横消→竖消→清空获胜、错误路线目标不足、整线回退和洗牌连锁。
- 恢复失败存档后立即回退的延迟弹窗问题已修正：弹窗显示前重新检查当前失败状态与动画队列。

研究参考：用户提供的1v1视频表现为插牌顶出、列排序；本关是据此讨论后独立设计的二合/重力/整线实验，不声称原PVP规则已经原样移植。
